OverflowBox & UnconstrainedBox

OverflowBox replaces the constraints its child receives, so the child can be larger than the box while the parent still believes the box is its original size. UnconstrainedBox removes the limits instead.

Use it for

A full-bleed banner inside a padded list, an oversized glow, a child that must escape its slot.

Watch out for

Parts painted outside the parent usually do not receive taps, because hit testing follows the parent bounds.

No layout errorrule-Unlike a plain overflow there are no yellow stripes, because you asked for it.

Example code

SizedBox(
  width: 190,
  height: 86,
  child: OverflowBox(
    maxWidth: 300,
    maxHeight: 110,
    alignment: Alignment.center,
    child: child,   // laid out with YOUR constraints
  ),
)
