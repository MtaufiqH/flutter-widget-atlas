image_picker (photos & camera)

image_picker is the Flutter team's plugin for choosing a photo or video from the gallery, or taking one with the camera. You call pickImage and get back an XFile (or null if the user cancelled). Then you show it, copy it, or upload it.

Use it for

Profile pictures, attaching photos to a post, scanning a receipt, and any "choose or take a picture" button.

Watch out for

Always handle null (the user cancelled) and errors (permission denied). On iOS, add the usage descriptions to Info.plist or the app crashes. Pass maxWidth, maxHeight or imageQuality to avoid uploading 12 MB photos. On web the XFile has no real file path, so read its bytes.

What you get back
XFile?class-null when the user cancelled, which you must handle.
file.path / readAsBytes() / name / length()members-A path you can wrap in File, the raw bytes (the only option on the web), the file name and its size.
Webnote-There is no File on the web. Use readAsBytes and Image.memory.
Setup that is easy to forget
iOS Info.plistconfig-NSCameraUsageDescription and NSPhotoLibraryUsageDescription. Without them the app is rejected, and the picker crashes on launch.
Androidconfig-Usually nothing for the modern photo picker. Camera capture needs a FileProvider, which the plugin supplies.
Lost data on Androidrule-Android can kill your app while the camera is open. Call retrieveLostData() on startup or you silently lose photos on low-memory devices.
Related packages
image_cropperpackage-Crop and rotate after picking.

Example code

// pubspec: image_picker
final picker = ImagePicker();

Future<void> choose() async {
  try {
    final XFile? file = await picker.pickImage(
      source: ImageSource.gallery,
      maxWidth: 1024,
      imageQuality: 80,
    );
    if (file == null) return;            // cancelled
    setState(() => _file = file);
  } on PlatformException catch (e) {
    // permission denied or camera not available
  }
}

// show it
Image.file(File(_file!.path))        // mobile
// web: Image.memory(await _file!.readAsBytes())

// iOS: ios/Runner/Info.plist
// NSPhotoLibraryUsageDescription  (why you read photos)
// NSCameraUsageDescription        (why you use the camera)
