Animation and motion

Hero

A Hero flies from one screen to the next during a route change. Put the same tag on a widget in both routes and Flutter animates the bounds between them while the rest of the page transitions normally.

Use it for

A thumbnail opening into a full picture, a list row expanding into a detail screen.

Watch out for

Exactly one Hero per tag may be on screen at a time, so in a list use the item id. Text inside a flying Hero needs a Material ancestor or it renders with yellow underlines.

Rules that make it work
One tag per routerule-Two Heroes with the same tag on screen at once throws. In a list, use the item id.
Both routes need itrule-No Hero on the destination means no animation, and no error either.
Text needs Materialrule-A flying Text can render with yellow underlines. Wrap the child in a Material with a transparent colour.
Size changesrule-The child is briefly laid out at both sizes, so avoid children that overflow at either end.

Example code

// list screen
Hero(
  tag: 'photo-${item.id}',
  transitionOnUserGestures: true,
  child: Image.network(item.thumb, width: 64, height: 48, fit: BoxFit.cover),
)

// detail screen: same tag
Hero(
  tag: 'photo-${item.id}',
  child: Image.network(item.full, height: 240, fit: BoxFit.cover),
)

Navigator.push(
  context,
  MaterialPageRoute(builder: (_) => DetailPage(item: item)),
);
