Animation and motion

AnimatedFractionallySizedBox

A FractionallySizedBox whose factors animate. Because the size is a fraction of the parent, it is the shortest way to write a progress bar or a panel that slides open, with no controller at all.

Use it for

Progress bars, meters, reveal panels and simple bar charts.

Watch out for

A fraction of infinity is undefined, so the parent must have a real size. A null factor leaves that axis alone, which lets you animate the width only.

Example code

AnimatedFractionallySizedBox(
  widthFactor: 0.65,   // change this and it animates
  heightFactor: 1.0,
  alignment: Alignment.centerLeft,
  duration: const Duration(milliseconds: 600),
  curve: Curves.easeOut,
  child: const ColoredBox(color: Colors.blue),
)
