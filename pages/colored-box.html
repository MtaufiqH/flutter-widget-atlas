Painting and effects

ColoredBox

ColoredBox paints one rectangle of colour behind its child, and does nothing else. It is the cheapest way to give something a background.

Use it for

A flat background behind a widget or a whole screen section.

Watch out for

It has no size of its own: it takes the space it is offered, or the size of its child. Pair it with SizedBox or Padding when you need dimensions.

Properties

Properties11
NameTypeDefaultWhat it does
ColoredBox
colorColorrequiredThe colour that fills the whole box.
childWidget?nullWhat sits inside. With no child it fills whatever space it is given.
Why it exists
Cheapest possible fillreason-It paints one rectangle and nothing else. Container with a colour creates a DecoratedBox with a BoxDecoration, which is more work for the same result.
const friendlyreason-const ColoredBox(color: Colors.white, child: ...) can be built once and reused, which Container with a colour cannot always do.
The alternatives, in order of cost
ColoredBoxwidget-Flat colour only.
DecoratedBoxwidget-Colour plus border, radius, gradient or shadow.
Container(color:)widget-Convenience: it becomes a ColoredBox internally when you only set a colour, but with extra layers around it.
Material(color:)widget-Use when you also need ink ripples, elevation or a shape.
Good to know
No size of its ownrule-ColoredBox takes the size its parent offers, or the size of its child. Pair it with SizedBox when you need dimensions.
Behind a listpattern-A ColoredBox around a ListView is cheaper than giving every row its own coloured Container.
Rarely needed

key

ColoredBox on api.flutter.dev

Example code

ColoredBox(
  color: Theme.of(context).colorScheme.surfaceContainer,
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: const Text('child'),
  ),
)

// when the colour is a constant, the whole thing can be const
const ColoredBox(color: Colors.white, child: Text('child'))
