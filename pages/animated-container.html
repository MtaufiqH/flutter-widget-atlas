Animation and motion

AnimatedContainer

AnimatedContainer takes the same arguments as Container, plus a duration. Rebuild it with different values and it animates from the old ones to the new ones. No controller, no State machinery.

Use it for

Selection states, expanding cards, colour changes and anything that should move rather than jump.

Watch out for

It animates the box, not the child. Swapping the child widget is instant: use AnimatedSwitcher for that. Two decorations only tween when they are the same kind.

What does not animate
A changed childrule-Swapping the child widget is instant. Use AnimatedSwitcher for that.
A gradient to a flat colourrule-Two decorations only tween when they are the same kind. Use a gradient on both sides.
A null to a valuerule-Going from no decoration to one jumps. Give both states the same shape.

Example code

AnimatedContainer(
  duration: const Duration(milliseconds: 500),
  curve: Curves.easeInOut,
  width: selected ? 200 : 110,
  height: selected ? 120 : 80,
  color: selected ? Colors.red : Colors.blue,
  onEnd: () => debugPrint('done'),
  child: const Text('child'),
)
