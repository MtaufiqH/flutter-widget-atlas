ConstraintsTransformBox

ConstraintsTransformBox rewrites the constraints before they reach the child. You pass a function from the incoming BoxConstraints to new ones, and the ready-made transforms cover the common cases.

Use it for

Letting a child escape one limit while keeping the others, usually so it can be its natural size on one axis.

Watch out for

Freeing a constraint often makes the child bigger than its slot, so set clipBehavior or expect the overflow stripes. UnconstrainedBox is this widget with the unconstrained transform.

Why it exists
UnconstrainedBox is a special caserelation-UnconstrainedBox is ConstraintsTransformBox with the unconstrained transform and a debug warning when the child overflows.
Writing your ownpattern-(constraints) => constraints.copyWith(maxHeight: double.infinity) lets a child grow vertically inside a fixed box, which you then clip.
Overflow is yours to handlewarning-Freeing a constraint often makes the child larger than the slot. Set clipBehavior or expect the yellow stripes.

Example code

ConstraintsTransformBox(
  constraintsTransform: ConstraintsTransformBox.widthUnconstrained,
  alignment: Alignment.center,
  clipBehavior: Clip.none,
  child: child,
)

// the simpler form for the common case
UnconstrainedBox(
  constrainedAxis: Axis.vertical,   // keep the OTHER axis limited
  child: child,
)
