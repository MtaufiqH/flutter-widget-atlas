Flavors and release

Android release: signing and App Bundle

To publish on Google Play you sign the app with a key, build an Android App Bundle (.aab), and upload it. Play then makes the right APK for each phone. The key proves that updates come from you.

Use it for

Shipping an Android app to testers or to the Play Store.

Watch out for

Back up your keystore and passwords. If you lose the upload key you must ask Google to reset it. Never commit the keystore or key.properties to git. Increase the build number in pubspec (the number after +) for each upload. Test the release build on a real phone, because it behaves differently from debug. Gradle files change between Flutter versions, so check the current Android deployment docs.

Example code

# 1. once per app. Keep the file safe and backed up.
keytool -genkey -v -keystore ~/upload-keystore.jks \
  -keyalg RSA -keysize 2048 -validity 10000 -alias upload
