Localization

Dates, numbers, currency and right-to-left

The same date, number and price look different in each country. 1,234,567.89 in the US is 1.234.567,89 in Germany. The intl package formats them for a locale. Right-to-left languages also mirror the layout, so use start and end instead of left and right.

Use it for

Showing dates, prices, quantities and distances to users in different regions.

Watch out for

Never build dates or prices by hand with string joins. A currency is not decided by the language: a German user may still pay in US dollars. Use EdgeInsetsDirectional and AlignmentDirectional so layouts mirror. Icons that show direction (back arrows) must mirror too. The page here uses the browser's own formatter, so Dart output may differ slightly.

Example code

// intl comes with flutter_localizations
final now = DateTime(2026, 11, 1, 14, 30);
final locale = 'en_US';

DateFormat.yMMMMd(locale).format(now);          // November 1, 2026
DateFormat.jm(locale).format(now);              // 6:30 AM
NumberFormat.decimalPattern(locale).format(1234567.89);   // 1,234,567.89
NumberFormat.simpleCurrency(locale: locale, name: 'USD').format(1234.5);   // $1,234.50

// use the app locale instead of a fixed one
final l = Localizations.localeOf(context).toString();

// if DateFormat says the locale data is missing:
// await initializeDateFormatting('en_US');

// layouts that mirror in right-to-left
Padding(
  padding: const EdgeInsetsDirectional.only(start: 16, end: 8),   // not left / right
  child: Align(
    alignment: AlignmentDirectional.centerStart,
    child: Text(title),
  ),
);

// force a direction, or test it
Directionality(textDirection: TextDirection.ltr, child: const MyRow());
// icons that point (a back arrow) should mirror: Icon(Icons.arrow_back) does it itself,
// custom images need matchTextDirection: true
