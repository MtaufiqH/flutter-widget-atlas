Text

Text.rich & RichText

Text.rich draws one paragraph made of several spans, each with its own style. A WidgetSpan puts a real widget inline, and a recognizer makes one span tappable.

Use it for

A sentence with a bold word, a price with a small currency symbol, inline links, text with an icon in the middle.

Watch out for

Prefer Text.rich over RichText: RichText does not scale with the user font setting by default. A TapGestureRecognizer must be disposed.

Example code

Text.rich(
  TextSpan(
    style: DefaultTextStyle.of(context).style.copyWith(fontSize: 16),
    children: const [
      TextSpan(text: 'Flutter draws '),
      TextSpan(text: 'every pixel', style: TextStyle(fontWeight: FontWeight.bold)),
      TextSpan(text: ' itself, which is why a '),
      TextSpan(text: 'TextSpan', style: TextStyle(fontFamily: 'monospace', backgroundColor: Color(0x1A2563EB))),
      TextSpan(text: ' can change '),
      TextSpan(text: 'style', style: TextStyle(color: Colors.red, fontStyle: FontStyle.italic)),
      TextSpan(text: ' mid sentence.'),
    ],
  ),
)
