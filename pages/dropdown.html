DropdownButton

DropdownButton shows the chosen value and opens a menu of DropdownMenuItems. DropdownMenu is the Material 3 version: it looks like a text field and can filter as you type.

Use it for

Choosing one value from a short, known list: a country, a size, a sort order.

Watch out for

value must equal exactly one item value or Flutter throws. With a custom class that means implementing == and hashCode. For a Form, use DropdownButtonFormField, which takes initialValue instead of value.

Example code

DropdownButton<String>(
  value: size,
  onChanged: (v) => setState(() => size = v),
  borderRadius: BorderRadius.circular(4),
  items: [
    for (final o in sizes)
      DropdownMenuItem(value: o, child: Text(o)),
  ],
)
