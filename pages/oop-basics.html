OOP in Dart: classes, constructors and encapsulation

A class is a blueprint and an object is one thing made from it. Constructors build objects: a default one, named ones, factories and const ones. Encapsulation hides the inside: a name starting with an underscore is private to its file, and getters and setters guard the value.

Use it for

Model your data and logic: User, Product, Repository, ViewModel. Almost every Flutter widget is a class.

Watch out for

Private in Dart means private to the library (usually the file), not to the class. Initialise final fields in the constructor, using this.name or an initializer list, because the body runs too late. A factory constructor may return an existing object. Mark classes const when all fields are final.

Example code

class Point {
  double x;
  double y;
  Point(this.x, this.y);

  @override
  String toString() => 'Point(x: $x, y: $y)';
}

// in another file:
final p = Point(3, 4);
p.x = -5;   // allowed: x is -5
