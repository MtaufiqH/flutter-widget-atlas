Painting and effects

CustomPaint

CustomPaint hands you a Canvas and a Size. You draw with Paint objects and Path geometry, and shouldRepaint decides when it runs again.

Use it for

Charts, progress rings, signatures, badges, decorations no widget covers.

Watch out for

Return the right value from shouldRepaint: returning true always repaints every frame. With no child and no size, CustomPaint collapses to zero.

Example code

class _Painter extends CustomPainter {
  _Painter({required this.progress}) ;

  final double progress;

  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()
      ..style = PaintingStyle.stroke
      ..strokeWidth = 12
      ..strokeCap = StrokeCap.round
      ..color = Colors.blue;

    final rect = Rect.fromCircle(
      center: size.center(Offset.zero),
      radius: size.shortestSide / 2 - 12,
    );
    canvas.drawArc(rect, 0, 2 * math.pi, false, track);
    canvas.drawArc(
      rect,
      -math.pi / 2,              // start at the top
      2 * math.pi * progress,    // sweep
      false,
      paint,
    );
  }

  @override
  bool shouldRepaint(_Painter old) => old.progress != progress;   // not just true
}

CustomPaint(
  size: const Size(150, 150),
  painter: _Painter(progress: 0.70),
  child: null,
)
