showDatePicker & showTimePicker

showDatePicker opens a dialog and returns the chosen DateTime, or null if the user cancels. showTimePicker does the same for a TimeOfDay, and showDateRangePicker for a range.

Use it for

Birthdays, booking dates, reminders, filters over a period.

Watch out for

initialDate must sit inside firstDate to lastDate and pass selectableDayPredicate, or it throws. Dart has no date formatting of its own: use DateFormat from the intl package.

Example code

final date = await showDatePicker(
  context: context,
  initialDate: DateTime.now(),
  firstDate: DateTime(2020),
  lastDate: DateTime(2030),
  initialEntryMode: DatePickerEntryMode.calendar,
  initialDatePickerMode: DatePickerMode.day,
);
if (date == null) return;   // the user cancelled

// formatting needs the intl package
final label = DateFormat.yMMMd().format(date);
