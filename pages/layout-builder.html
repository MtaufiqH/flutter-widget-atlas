LayoutBuilder & MediaQuery

LayoutBuilder tells a widget how much space it was given. MediaQuery describes the window: its size, the system padding, the keyboard and the user font setting. They answer different questions.

Use it for

LayoutBuilder for a widget that adapts to its slot. MediaQuery for a whole screen, or for the keyboard and safe areas.

Watch out for

MediaQuery.sizeOf(context) is the window, not your slot. Use the .sizeOf and .paddingOf forms so the widget rebuilds only when that one value changes.

builderFunction(BuildContext, BoxConstraints)requiredCalled with the constraints this spot in the tree was given. Return a widget built from them.
What the constraints tell you
constraints.maxWidth / maxHeightdouble-The most space available here. The number people actually use.
constraints.minWidth / minHeightdouble-The least the child may be. Often zero, and equal to max when the parent is tight.
constraints.hasBoundedHeightbool-False inside a scroll view, where maxHeight is infinity. Check it before dividing by the height.
What it is not
Not the screen sizedifference-It is the space this widget was given, which is what you want for a card that must adapt inside a sidebar. MediaQuery gives the window instead.
Runs during layoutrule-The builder runs after the parent has laid out, so you cannot call setState from it, and it may run more than once per frame.
MediaQuery, the other half
MediaQuery.sizeOf(context)Size-The window size. Use the .sizeOf form, not MediaQuery.of(context).size, so your widget only rebuilds when the size changes.
MediaQuery.paddingOf(context)EdgeInsets-Status bar, home indicator and notches. SafeArea is built on this.
MediaQuery.viewInsetsOf(context)EdgeInsets-The keyboard. viewInsets.bottom is its height.
MediaQuery.textScalerOf(context)TextScaler-The user font-size setting. Test your layout at 2x before you ship.
MediaQuery.platformBrightnessOf(context)Brightness-Light or dark at the system level.
MediaQuery.orientationOf(context)Orientation-Portrait or landscape.
MediaQuery.of(context).accessibleNavigation / disableAnimationsbool-Whether a screen reader is on, and whether the user asked for reduced motion.
Choosing between them
Use LayoutBuilderwhen-A widget should adapt to its own slot: a card that becomes two columns when wide enough.
Use MediaQuerywhen-A whole screen should change for phone, tablet or desktop, or you need the keyboard, padding or text scale.
Breakpointspattern-Material suggests about 600, 840 and 1200 logical pixels. Put them in one file and reuse the names.
Related
OrientationBuilderwidget-A LayoutBuilder that reports portrait or landscape.
SliverLayoutBuilderwidget-The sliver version, inside a CustomScrollView.
FittedBox / FractionallySizedBoxwidget-Often enough when you only need to scale or take a share of the space.

Example code

LayoutBuilder(
  builder: (context, constraints) {
    final w = constraints.maxWidth;   // the space THIS widget was given
    if (w < 600) return const OneColumn();
    if (w < 900) return const TwoColumns();
    return const ThreeColumns();
  },
)

// the other MediaQuery values worth knowing
final padding = MediaQuery.paddingOf(context);        // notch, status bar, home indicator
final insets = MediaQuery.viewInsetsOf(context);      // keyboard height: insets.bottom
final scaler = MediaQuery.textScalerOf(context);      // user font size
final dark = MediaQuery.platformBrightnessOf(context) == Brightness.dark;
final landscape = MediaQuery.orientationOf(context) == Orientation.landscape;
final reduceMotion = MediaQuery.of(context).disableAnimations;
