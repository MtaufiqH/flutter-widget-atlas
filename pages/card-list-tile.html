Card & ListTile

Card is a Material surface with elevation and rounded corners. ListTile is the standard row: a leading widget, one or two lines of text and a trailing widget, with the Material spacing already right.

Use it for

Lists of items, settings screens and anything that groups a few rows together.

Watch out for

Put the InkWell inside the Card, not around it, or the ripple paints over the rounded corners. A Card has a default margin of 4, which you often want to clear in a list that has its own padding.

Example code

Card(
  elevation: 4,
  margin: const EdgeInsets.all(4),
  shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
  clipBehavior: Clip.antiAlias,   // so children follow the corners
  child: Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      ListTile(
        leading: const CircleAvatar(child: Text('A')),
        title: const Text('Wi-Fi'),
        subtitle: const Text('Connected to Home-5G'),
        trailing: const Icon(Icons.chevron_right),
        onTap: () {},
      ),
      const Divider(height: 1, indent: 72),
      // ... more tiles
    ],
  ),
)
