Input

TextField

TextField takes typed input. The InputDecoration object controls how it looks: label or hint, icons, helper and error text, and the character counter.

Use it for

Any single-value text entry. Use TextFormField when it lives in a Form with validation.

Watch out for

Create the TextEditingController in initState and dispose it. Creating it inside build wipes the text on every rebuild.

Example code

TextField(
  controller: controller,
  onSubmitted: (value) => setState(() => submitted = value),
  onChanged: (value) => setState(() => text = value),
  decoration: InputDecoration(
    labelText: 'Email',
    prefixIcon: Icon(Icons.person),
    border: OutlineInputBorder(),
  ),
)
