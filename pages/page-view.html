Scrolling

PageView

PageView shows one page at a time and lets the user swipe between them. Give it a PageController to control it from code: jumpToPage moves instantly, animateToPage glides, nextPage and previousPage step by one. A viewportFraction below 1 makes neighbouring pages peek in.

Use it for

Onboarding screens, image carousels, tabbed content, and any screen where a button or dot also has to change the page.

Watch out for

Create the PageController once in initState and dispose it. Making a new one inside build resets the page on every rebuild. controller.page is null until the first layout, so read it after the first frame or use onPageChanged. Call hasClients before using the controller if the PageView may not be on screen.

Example code

class _PagerState extends State<Pager> {
  final controller = PageController(
    initialPage: 0,
    viewportFraction: 0.85,
  );
  int current = 0;

  @override
  void dispose() {
    controller.dispose();   // always dispose
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Column(children: [
      Expanded(
        child: PageView(
          controller: controller,
          onPageChanged: (i) => setState(() => current = i),
          children: [/* 5 pages */],
        ),
      ),
      Row(children: [
        TextButton(
          onPressed: () => controller.previousPage(
            duration: const Duration(milliseconds: 500),
            curve: Curves.easeInOut,
          ),
          child: const Text('Back'),
        ),
        TextButton(
          onPressed: () {
            controller.animateToPage(
              3,
              duration: const Duration(milliseconds: 500),
              curve: Curves.easeInOut,
            );
          },
          child: const Text('Go to page 3'),
        ),
        TextButton(
          onPressed: () => controller.nextPage(
            duration: const Duration(milliseconds: 500),
            curve: Curves.easeInOut,
          ),
          child: const Text('Next'),
        ),
      ]),
    ]);
  }
}
