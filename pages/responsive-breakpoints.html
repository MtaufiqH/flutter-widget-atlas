Responsive layout: breakpoints and window size classes

A responsive layout changes with the space it has. Material 3 groups widths into window size classes: compact (under 600 dp), medium (600 to 839), expanded (840 and above). On a phone you show one column, on a tablet a grid, and on a wide screen a list with a detail pane.

Use it for

Apps that run on phones, tablets, foldables, the web and desktop windows that the user can resize.

Watch out for

Decide by the space your widget gets (LayoutBuilder), not by the device type. Use MediaQuery.sizeOf(context) to read the window size without rebuilding for unrelated changes. Do not lock the orientation without a reason. Limit the width of text lines on wide screens. Test a resizable window.

Example code

// Material 3 window size classes
enum WindowClass { compact, medium, expanded }
WindowClass windowClassOf(double width) =>
    width < 600 ? WindowClass.compact
    : width < 840 ? WindowClass.medium
    : WindowClass.expanded;

// the space THIS widget gets (best for reusable widgets)
LayoutBuilder(
  builder: (context, box) {
    switch (windowClassOf(box.maxWidth)) {
      case WindowClass.compact:
        return const ItemList();                         // one column
      case WindowClass.medium:
        return const ItemGrid(columns: 2);
      case WindowClass.expanded:
        return const Row(children: [
          SizedBox(width: 320, child: ItemList()),
          Expanded(child: DetailPane()),
        ]);
    }
  },
);

// a grid that picks the number of columns itself
GridView.builder(
  gridDelegate: const SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: 220),
  itemBuilder: (_, i) => ItemCard(items[i]),
);

// keep long text readable on wide screens
Center(child: ConstrainedBox(constraints: const BoxConstraints(maxWidth: 720), child: content));
