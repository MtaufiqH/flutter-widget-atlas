SnackBar

A short message at the bottom of the screen, shown through ScaffoldMessenger. It can carry one action, and it disappears by itself after a few seconds.

Use it for

Confirm something happened, with an optional Undo. Not for anything the user must read or act on.

Watch out for

Use ScaffoldMessenger.of(context).showSnackBar, not Scaffold.of. Bars are queued, so three calls show three in a row: call clearSnackBars first if you only want the latest.

Example code

ScaffoldMessenger.of(context).showSnackBar(
  SnackBar(
    content: Text('Project deleted'),
    action: SnackBarAction(label: 'UNDO', onPressed: restoreProject),
    behavior: SnackBarBehavior.floating,
    margin: const EdgeInsets.all(12),
    shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(8)),
    duration: const Duration(seconds: 4),
  ),
);

// learn what happened to it
