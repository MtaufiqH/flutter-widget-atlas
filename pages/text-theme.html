Theming and resources

TextTheme (typography)

TextTheme is a set of 15 named text styles: display, headline, title, body and label, each in large, medium and small. You pick a style by its role (titleLarge, bodyMedium) and the theme decides the size, weight and font. Change the font once in the theme and the whole app follows.

Use it for

Every Text in your app. Use a role from the theme and change only what is special with copyWith, for example the colour.

Watch out for

Do not write TextStyle(fontSize: 18) in each widget. The sizes shown are the Material 3 defaults. They are in logical pixels and they scale with the user's font-size setting, so test with a large text scale. For a custom font, add it in pubspec.yaml, or use the google_fonts package.

Properties

Properties7
NameTypeDefaultWhat it does
displayLarge / Medium / SmallTextStyle?57 / 45 / 36 spLargest text, for short hero text.
headlineLarge / Medium / SmallTextStyle?32 / 28 / 24 spScreen and section headings.
titleLarge / Medium / SmallTextStyle?22 / 16 / 14 spTitles of cards, app bars and list items.
bodyLarge / Medium / SmallTextStyle?16 / 14 / 12 spReading text. bodyMedium is the default for Text.
labelLarge / Medium / SmallTextStyle?14 / 12 / 11 spButtons, chips and captions.
copyWith(...)method-Change one property, for example color, and keep the rest.
apply(fontFamily: ...)method-Set one font on every style in the theme.

Example code

// use a role
Text(
  'Flutter',
  style: Theme.of(context).textTheme.titleLarge,
)

// change only one thing
Text(
  'Flutter',
  style: Theme.of(context).textTheme.titleLarge?.copyWith(
    color: Theme.of(context).colorScheme.primary,
  ),
)

// lib/core/theme/app_text_theme.dart
// override sizes in one place if you must
const textTheme = TextTheme(
  titleLarge: TextStyle(fontSize: 22, fontWeight: FontWeight.w600),
);
ThemeData(colorScheme: scheme, textTheme: textTheme)
