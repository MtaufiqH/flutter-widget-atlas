CustomScrollView & Slivers

A CustomScrollView stitches several scrolling pieces into one. Each piece is a sliver: a collapsing app bar, a lazy list, a grid, a single widget. One scroll position covers all of them.

Use it for

A header that collapses over a list, a screen that mixes a grid and a list, anything a Column of scroll views cannot do.

Watch out for

Only slivers may go in the slivers list. An ordinary widget needs SliverToBoxAdapter, and padding needs SliverPadding.

Example code

CustomScrollView(
  slivers: [
    SliverAppBar(
      expandedHeight: 150,
      pinned: true,
      flexibleSpace: FlexibleSpaceBar(
        title: const Text('Gallery'),
        background: Image.network(url, fit: BoxFit.cover),
        collapseMode: CollapseMode.parallax,
      ),
    ),
    SliverList.builder(
      itemCount: items.length,
      itemBuilder: (context, i) => ListTile(title: Text(items[i])),
    ),
  ],
)
