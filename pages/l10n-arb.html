Localization: ARB files, placeholders and plurals

Flutter's built-in localization keeps every text in an ARB file (a JSON file) for each language. A tool turns them into a Dart class, so your code calls l10n.hello(name) and the right language comes out. Plurals and placeholders are part of the file, so translators can handle them.

Use it for

Any app that will show more than one language, or that may later.

Watch out for

Put every user-visible string in the ARB files from the start, because adding them later is slow. Never join sentences with + , because word order changes between languages. Plural rules differ per language (Arabic has six forms), so let the ICU plural syntax handle them. Test right-to-left languages. Details of the generator change between versions, so check the current docs.

Example code

# pubspec.yaml
flutter:
  generate: true
dependencies:
  flutter_localizations:
    sdk: flutter
  intl: any            # use the version flutter pub add chooses

# l10n.yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart

// lib/l10n/app_en.arb  (the template, with descriptions)
{
  "@@locale": "en",
  "hello": "Hello, {name}!",
  "@hello": { "placeholders": { "name": { "type": "String" } } },
  "unread": "{count, plural, =0{No messages} =1{One message} other{{count} messages}}",
  "@unread": { "placeholders": { "count": { "type": "int" } } }
}

// lib/l10n/app_en.arb
{
  "hello": "Hello, {name}!",
  "unread": "{count, plural, =0{No messages} =1{One message} other{{count} messages}}"
}

// main.dart
MaterialApp(
  localizationsDelegates: AppLocalizations.localizationsDelegates,
  supportedLocales: AppLocalizations.supportedLocales,
  // locale: Locale('en'),   // optional: force a language
  home: const HomePage(),
);

// use it
final l10n = AppLocalizations.of(context)!;
Text(l10n.hello('Taufiq'));
Text(l10n.unread(1));

// generate (or just run the app):  flutter gen-l10n
