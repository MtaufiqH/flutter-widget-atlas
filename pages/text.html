Text

Text

Text draws a string with a TextStyle. Wrapping, alignment and what happens to text that does not fit (overflow) are all controlled by a handful of properties. Every control below is a real argument of Text or TextStyle.

Use it for

Every label, paragraph and heading.

Watch out for

overflow only matters when text cannot wrap: with no maxLines the text just wraps and you will never see an ellipsis. height is a multiple of fontSize, not a pixel value. Setting style replaces nothing you do not name, because it is merged with the DefaultTextStyle.

Example code

Text(
  'Flutter draws every pixel itself...',
  maxLines: 2,
  overflow: TextOverflow.ellipsis,
  style: TextStyle(
    fontSize: 18,
  ),
)
