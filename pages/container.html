Basics

Container

Container is a convenience widget that combines sizing, padding, margin, alignment and painting (color, border, radius, shadow, gradient) in one place. Every control below is a real Container argument.

Use it for

A styled box. If you only need one of those jobs, a dedicated widget (Padding, SizedBox, DecoratedBox) is lighter.

Watch out for

You cannot set both color and decoration. Put the color inside BoxDecoration instead. Setting alignment makes the Container expand to fill its parent. transform runs after layout, so a rotated Container still takes its original space.

Example code

Container(
  width: 170,
  height: 110,
  padding: const EdgeInsets.all(12),
  alignment: Alignment.center,
  decoration: BoxDecoration(
    color: Colors.blue.shade100,
    borderRadius: BorderRadius.circular(16),
    border: Border.all(width: 3, color: Colors.blue),
    boxShadow: const [BoxShadow(blurRadius: 18, offset: Offset(0, 8))],
  ),
  child: const Text('Hello'),
)
