Deep links: a URL that opens your app

A deep link is a URL that opens a screen inside your app. A verified https link is the safe kind: the phone checks that your site and your app belong together. A custom scheme like myapp:// is simpler, but any app can claim it.

Use it for

Links in emails and messages, QR codes, push notification taps, and sharing a page of your app.

Watch out for

Unverified https links open in the browser. You must host a verification file on your own domain (assetlinks.json for Android, apple-app-site-association for iOS). Test a cold start and a running app, because they take different paths. Your router must handle unknown paths. Check the current Flutter deep-linking docs for your version.

Example code

<!-- android/app/src/main/AndroidManifest.xml (inside <activity>) -->
<intent-filter android:autoVerify="true">
  <action android:name="android.intent.action.VIEW"/>
  <category android:name="android.intent.category.DEFAULT"/>
  <category android:name="android.intent.category.BROWSABLE"/>
  <data android:scheme="https" android:host="example.com"/>
</intent-filter>

// https://example.com/.well-known/assetlinks.json
// lists your package name and signing certificate fingerprint

// iOS: Xcode > Signing & Capabilities > Associated Domains
//   applinks:example.com
// https://example.com/.well-known/apple-app-site-association

// Dart: go_router receives the path from the platform.
// A route for /users/:id is all you need:
GoRoute(path: '/users/:id', builder: (_, s) => UserPage(id: s.pathParameters['id']!));

// a custom scheme needs its own intent-filter and CFBundleURLTypes:
// <data android:scheme="myapp" android:host="users"/>
