Theming and resources

ThemeData & ColorScheme.fromSeed

ThemeData holds the look of your whole app: colours, text styles, shapes and the style of every Material widget. You create it once, give it to MaterialApp, and every widget below reads from it with Theme.of(context). The easy start is ColorScheme.fromSeed, which builds a full matching set of colours from one seed colour.

Use it for

Setting the look of the whole app from one place, so a rebrand or a dark mode is a small change and not a search through every screen.

Watch out for

Material 3 is the default in current Flutter, so you do not need useMaterial3: true any more. Build the theme in one file (for example lib/core/theme/app_theme.dart), not inside build methods. Read it with Theme.of(context), and never hard-code Colors.blue in widgets.

Example code

// lib/core/theme/app_theme.dart
abstract final class AppTheme {
  static ThemeData get light => _build(Brightness.light);
  static ThemeData get dark => _build(Brightness.dark);

  static ThemeData _build(Brightness brightness) {
    final scheme = ColorScheme.fromSeed(
      seedColor: Colors.blue,
      brightness: Brightness.light,
    );
    return ThemeData(
      colorScheme: scheme,
      // textTheme, component themes, extensions...
    );
  }
}

// main.dart
MaterialApp(
  theme: AppTheme.light,
  darkTheme: AppTheme.dark,
  home: HomePage(),
)

// anywhere below MaterialApp
final scheme = Theme.of(context).colorScheme;
Container(color: scheme.primaryContainer)
