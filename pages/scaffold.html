Scaffold

Scaffold is the frame of a Material screen. It positions the app bar, the body, a floating action button, bottom and drawer panels, and it handles the keyboard inset for you.

Use it for

Almost every screen in a Material app.

Watch out for

Scaffold.of(context) must be called below the Scaffold, so wrap the caller in a Builder. For snack bars use ScaffoldMessenger, which survives the Scaffold being replaced.

Example code

Scaffold(
  appBar: AppBar(title: const Text('Title')),
  body: const Content(),
  floatingActionButton: FloatingActionButton(
    onPressed: () {},
    child: const Icon(Icons.add),
  ),
  floatingActionButtonLocation: FloatingActionButtonLocation.endFloat,
  bottomNavigationBar: NavigationBar(
    selectedIndex: index,
    onDestinationSelected: (i) => setState(() => index = i),
    destinations: destinations,
  ),
  drawer: const AppDrawer(),
)
