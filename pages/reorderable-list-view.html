Scrolling

ReorderableListView

ReorderableListView lets the user drag rows into a new order. Every child needs a unique key, and your callback has to move the item in your own list.

Use it for

Playlists, task order, a list of steps the user arranges.

Watch out for

The index fix catches everyone: when newIndex is greater than oldIndex you must subtract one before inserting, because the item is removed first.

Example code

ReorderableListView.builder(
  itemCount: items.length,
  proxyDecorator: (child, index, animation) => Material(
    elevation: 8,
    borderRadius: BorderRadius.circular(10),
    child: child,
  ),
  onReorderItem: (oldIndex, newIndex) {
    setState(() {
      if (newIndex > oldIndex) newIndex -= 1;   // the fix everyone forgets
      final item = items.removeAt(oldIndex);
      items.insert(newIndex, item);
    });
  },
  itemBuilder: (context, i) => ListTile(
    key: ValueKey(items[i].id),
    title: Text(items[i].title),
  ),
)
