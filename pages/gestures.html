Interaction models

GestureDetector

GestureDetector turns raw pointer events into gestures: taps, long presses, drags and pinches. It draws nothing, so what it covers depends on its child and on behavior.

Use it for

Any custom tap or drag target. For anything inside a Material app that should ripple, use InkWell instead.

Watch out for

behavior: deferToChild means empty space in the child is not tappable. Pan and scale callbacks cannot be used together. A horizontal drag inside a vertical list should use onHorizontalDrag, not onPan.

Example code

GestureDetector(
  behavior: HitTestBehavior.deferToChild,
  onPanStart: (d) => setState(() => dragging = true),
  onPanUpdate: (d) => setState(() => offset += d.delta),
  onPanEnd: (d) => setState(() {
    dragging = false;
    velocity = d.velocity.pixelsPerSecond;
  }),
  child: child,
)
