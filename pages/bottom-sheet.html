BottomSheet

A panel that slides up from the bottom. showModalBottomSheet dims the screen behind it; a persistent sheet lets the user keep using the screen. For a sheet the user can drag between sizes, use DraggableScrollableSheet.

Use it for

A short list of actions, a filter panel, a form that does not deserve a whole screen.

Watch out for

Any sheet taller than half the screen, or holding a text field, needs isScrollControlled: true. Add padding for MediaQuery.viewInsets so the keyboard does not cover the field.

Example code

final result = await showModalBottomSheet<String>(
  context: context,
  showDragHandle: true,
  shape: const RoundedRectangleBorder(
    borderRadius: BorderRadius.vertical(top: Radius.circular(20)),
  ),
  builder: (context) => content,
);
