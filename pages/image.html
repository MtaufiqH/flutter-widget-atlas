Image & BoxFit

Image shows a picture from the network, an asset, a file or memory. When the image and the box it lives in have different shapes, BoxFit decides how the picture is scaled and cropped, and alignment decides which part survives the crop.

Use it for

Photos, avatars and artwork. Use cover to fill a box and contain to show the whole picture.

Watch out for

Image.network shows nothing while loading and nothing on error unless you give it loadingBuilder and errorBuilder. Decoding a large photo into a small box wastes memory: pass cacheWidth. Image.network has no disk cache, so use cached_network_image in production.

Example code

Image.network(
  'https://example.com/photo.jpg',
  width: 200, height: 140,
  fit: BoxFit.cover,
  cacheWidth: 400,   // decode at the size you draw
)
