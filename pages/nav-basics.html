Navigation and routing

Navigator: push, pop and results

Navigator keeps a stack of pages. push puts a new page on top, pop removes the top one. You can send data to the new page through its constructor, and send a result back through pop.

Use it for

Moving between a few screens, opening a detail page, and asking a page for a value (a picker, a confirmation).

Watch out for

After an await, check context.mounted before you use the context again. The last page cannot be popped. Pass real objects through a constructor when you can, because arguments are not type-checked. For deep links, the web, and many routes, use go_router.

Navigator.pop(context, [result])void-Removes the top page and returns a result.

Example code

Navigator.push(
  context,
  MaterialPageRoute(builder: (_) => DetailsPage(id: 7)),
);

class DetailsPage extends StatelessWidget {
  const DetailsPage({super.key, required this.id});
  final int id;   // typed, checked by the compiler
  ...
}

// go back
Navigator.pop(context);
// swap the top page (after login)
Navigator.pushReplacement(context, route);
// open a page and drop everything above Home
Navigator.pushAndRemoveUntil(context, route, (r) => r.isFirst);
