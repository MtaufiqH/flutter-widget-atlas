Autocomplete

Autocomplete shows a dropdown of matches as the user types. You supply optionsBuilder, which returns the matches for the current text, and onSelected, which receives the chosen one.

Use it for

Picking a known value quickly: a city, a tag, a contact.

Watch out for

Return an empty list for empty input, or every option appears the moment the field is focused. optionsBuilder runs on every keystroke, so debounce any network call.

Example code

Autocomplete<String>(
  optionsBuilder: (TextEditingValue value) {
    if (value.text.isEmpty) return const Iterable<String>.empty();
    return cities.where(
      (c) => c.toLowerCase().contains(value.text.toLowerCase()),
    );
  },
  onSelected: (city) => setState(() => selected = city),
  fieldViewBuilder: (context, controller, focusNode, onFieldSubmitted) {
    return TextFormField(
      controller: controller,
      focusNode: focusNode,
      decoration: const InputDecoration(
        labelText: 'Search a city',
        prefixIcon: Icon(Icons.search),
        border: OutlineInputBorder(),
      ),
      validator: (v) => v == null || v.isEmpty ? 'Pick a city' : null,
    );
  },
)
