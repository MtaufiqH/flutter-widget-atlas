Networking and data

Local storage: which one to use

Flutter has no single built-in database. The Flutter cookbook shows three options: files, key-value storage and SQLite. Each fits a different kind of data. Choosing the wrong one is a common beginner mistake, for example saving a login token in plain key-value storage.

Use it for

Deciding where to save settings, tokens, lists of records and downloaded files.

Watch out for

Anything secret goes to the platform's secure storage, never to shared_preferences. Large or related data goes to a database. Files are for blobs such as images and PDFs. Always check that a package is maintained before you depend on it.

Properties

Properties6
NameTypeDefaultWhat it does
shared_preferencespackage-Small key-value data: settings and flags. Not secure.
flutter_secure_storagepackage-Tokens and secrets, stored with Keychain or Keystore.
sqflitepackage-SQLite with SQL strings and helper methods.
driftpackage-SQLite with typed Dart queries and streams. Needs build_runner.
path_provider + dart:io Filepackages-Folders and files for images, PDFs and exports.
Webnote-Some of these work differently or not at all on Flutter web. Check each package.

Example code

// pubspec: shared_preferences
final prefs = await SharedPreferences.getInstance();

await prefs.setBool('darkMode', true);
final dark = prefs.getBool('darkMode') ?? false;

// a small object as JSON
await prefs.setString('profile', jsonEncode(profile.toJson()));
final json = prefs.getString('profile');
final p = json == null
    ? null
    : Profile.fromJson(jsonDecode(json) as Map<String, dynamic>);
