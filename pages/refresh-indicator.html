Scrolling

RefreshIndicator

RefreshIndicator shows a spinner when the user pulls down past the top of a scrollable, and keeps it turning until the Future you return completes.

Use it for

Reloading a feed, a list of messages or anything the server can change.

Watch out for

The child must really be scrollable. On a short list add physics: AlwaysScrollableScrollPhysics(), or the pull does nothing at all.

Example code

RefreshIndicator(
  onRefresh: () async {
    await api.reload();   // the spinner turns until this completes
    if (!mounted) return;
    setState(() {});
  },
  child: ListView.builder(
    physics: const AlwaysScrollableScrollPhysics(),
    itemCount: items.length,
    itemBuilder: (context, i) => ListTile(title: Text(items[i])),
  ),
)
