Scrolling

NestedScrollView

NestedScrollView coordinates an outer header with inner scroll views. It is what you need when a collapsing header sits above tabs, each tab scrolling its own list.

Use it for

A profile screen with a big header and tabs, where scrolling a tab collapses the header.

Watch out for

Wrap the SliverAppBar in a SliverOverlapAbsorber and start each inner list with a SliverOverlapInjector, or the first rows hide behind the pinned bar.

The parts that make it work
SliverOverlapAbsorber / SliverOverlapInjectorwidget-Wrap the SliverAppBar in an absorber and put an injector at the top of each inner list, or the first items hide behind the pinned bar.
NestedScrollView.sliverOverlapAbsorberHandleFor(context)method-The handle both of those need.
PrimaryScrollControllerwidget-Inner lists pick up the inner controller automatically, which is why a plain ScrollController on an inner list often does nothing.
When you need it
Header plus tabscase-A profile screen with a collapsing header and tabs, each tab scrolling its own list. A plain CustomScrollView cannot do this.
When you do notcase-One list with a collapsing header needs only a CustomScrollView with a SliverAppBar.
Known rough edges
Keeping tab scroll positionsissue-Add a PageStorageKey to each inner list so its offset survives a tab switch.
Inner list must be a sliver-friendly scroll viewrule-Use CustomScrollView with SliverList inside each tab for the smoothest result.

Example code

DefaultTabController(
  length: 3,
  child: NestedScrollView(
    headerSliverBuilder: (context, innerBoxIsScrolled) => [
      SliverOverlapAbsorber(
        handle: NestedScrollView.sliverOverlapAbsorberHandleFor(context),
        sliver: SliverAppBar(
          expandedHeight: 150,
          pinned: true,
          forceElevated: innerBoxIsScrolled,
          flexibleSpace: const FlexibleSpaceBar(title: Text('Profile')),
          bottom: const TabBar(tabs: [Tab(text: 'Posts'), Tab(text: 'Media'), Tab(text: 'Likes')]),
        ),
      ),
    ],
    body: const TabBarView(
      children: [PostsTab(), MediaTab(), LikesTab()],
    ),
  ),
)

// inside each tab
CustomScrollView(
  key: const PageStorageKey('posts'),
  slivers: [
    SliverOverlapInjector(
      handle: NestedScrollView.sliverOverlapAbsorberHandleFor(context),
    ),
    SliverList.builder(
      itemCount: posts.length,
      itemBuilder: (context, i) => ListTile(title: Text(posts[i])),
    ),
  ],
)
