Painting and effects

Opacity

Opacity fades its child and everything inside it as one layer. That is the important part: overlapping shapes fade together, instead of each one becoming see-through on its own.

Use it for

Dimming a whole group, a disabled state, or a fade you drive yourself.

Watch out for

Any value between 0 and 1 forces an offscreen layer, which costs real time in lists and animations. Fading a single colour with Color.withValues(alpha:) is free.

Cheaper ways to do the same thing
Color.withValues(alpha:)method-Fading one colour costs nothing. Prefer it over wrapping a widget in Opacity.
AnimatedOpacitywidget-Same idea with duration and curve. Still uses a layer while animating.
FadeTransition(opacity: animation)widget-The cheapest animated fade, because it repaints without rebuilding.
Visibility(visible:)widget-Removes the child from the tree instead of painting it transparently. Use this when the widget should not be there at all.
Offstage(offstage:)widget-Keeps the child alive and laid out but does not paint it.
Good to know
Costperformance-Any opacity between 0 and 1 forces Flutter to paint the child into an offscreen buffer. In a list or an animation that shows up on the devtools timeline.
opacity: 0 still lays outrule-The child still takes its space and still handles taps. Wrap it in IgnorePointer if it should not.
Nested opacityrule-Opacity multiplies down the tree, so 0.5 inside 0.5 paints at 0.25.
