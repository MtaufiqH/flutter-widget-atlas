Testing and quality

Widget tests: pumpWidget, find, tap, pump

A widget test builds a widget in a fake test environment, finds things on it, taps them, and checks the result. It runs without a phone, so it is fast. You must call pump after an action so the screen redraws.

Use it for

Checking that a button changes the screen, a form shows errors, or a list shows the right items.

Watch out for

Wrap the widget in MaterialApp (or the app's providers), because many widgets need them. Call await tester.pump() after tap, and pumpAndSettle() when animations must finish. Prefer find.byKey for important widgets. Pass fakes in, not real services. Finders and matchers can change slightly between versions.

Example code

// test/counter_page_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';

void main() {
  testWidgets('counter increments', (tester) async {
    // 1. build the widget (it needs MaterialApp around it)
    await tester.pumpWidget(const MaterialApp(home: CounterPage()));

    // 2. find
    expect(find.text('0'), findsOneWidget);

    // 3. act
    await tester.tap(find.byIcon(Icons.add));
    await tester.pump();            // 4. redraw one frame

    // 5. check
    expect(find.text('1'), findsOneWidget);
  });
}

// animations: await tester.pumpAndSettle();
// a widget with a provider: wrap it
//   ChangeNotifierProvider.value(value: FakeVm(), child: ...)
// run:  flutter test
