FractionalTranslation

FractionalTranslation moves its child by a fraction of the child size, so you never need to know how big it is. Offset(0.5, 0) moves it right by exactly half its own width.

Use it for

Nudging a badge half outside its corner, and any slide whose distance should follow the widget size.

Watch out for

Like every transform it moves the painting, not the layout. Neighbours do not move, and the child may overlap them.

Why fractions
Size-independent offsetsreason-You do not need to know the child size. A badge can be pushed out by exactly half its width whatever its content.
Painting onlyrule-Like every Transform, it moves the painting, not the layout. Neighbours do not move, and the child can overlap them.
Related
SlideTransition(position: Animation<Offset>)widget-The animated version, and the one used for slide-in page transitions. Offsets are fractions here too.
AnimatedSlide(offset:, duration:)widget-The implicit version with no controller.
Transform.translate(offset:)widget-Pixels instead of fractions.
Align with a fractional alignmentalternative-Often clearer when the child must stay inside its parent.

Example code

Stack(
  clipBehavior: Clip.none,
  children: [
    const Avatar(),
    Positioned(
      right: 0,
      top: 0,
      child: FractionalTranslation(
        translation: const Offset(0.5, -0.5),   // fractions of the badge size
        child: const Badge(count: 3),
      ),
    ),
  ],
)

// the animated version uses the same units
AnimatedSlide(
  offset: const Offset(0.5, -0.5),
  duration: const Duration(milliseconds: 250),
  child: child,
)
