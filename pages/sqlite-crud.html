SQLite CRUD (sqflite & drift)

SQLite is a database file inside the app. You create tables once, then Create, Read, Update and Delete rows. sqflite gives you SQL with small helper methods. drift lets you describe tables in Dart and generates type-safe queries.

Use it for

Offline lists, notes, carts, caches and any data with many records that you search or sort.

Watch out for

Open the database once and reuse it. Never build SQL by joining strings, use ? and whereArgs. Change the schema by raising the version and writing onUpgrade, or users lose data. Group several writes in a transaction or batch.

Example code

// open ONCE and reuse (for example in a service)
final db = await openDatabase(
  join(await getDatabasesPath(), 'app.db'),
  version: 1,           // raise it when the schema changes
  onCreate: (db, v) => db.execute(
    'CREATE TABLE todos(id INTEGER PRIMARY KEY AUTOINCREMENT, '
    'title TEXT NOT NULL, done INTEGER NOT NULL DEFAULT 0)',
  ),
  onUpgrade: (db, oldV, newV) async { /* migrate */ },
);

await db.insert(
  'todos',
  {'title': 'Item', 'done': 0},
  conflictAlgorithm: ConflictAlgorithm.replace,
);
