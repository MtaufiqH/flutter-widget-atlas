Dismissible

Dismissible lets the user swipe a row away. You give it a unique key, a background that shows while swiping, and a callback that removes the item from your list.

Use it for

Swipe to delete, archive or mark as read.

Watch out for

The key must be unique and stable, usually ValueKey(item.id). In onDismissed you must remove the item from your data, or the next build throws.

Example code

Dismissible(
  key: ValueKey(item.id),
  background: Container(
    color: Colors.green,
    alignment: Alignment.centerLeft,
    padding: const EdgeInsets.only(left: 18),
    child: const Icon(Icons.archive, color: Colors.white),
  ),
  secondaryBackground: Container(
    color: Colors.red,
    alignment: Alignment.centerRight,
    padding: const EdgeInsets.only(right: 18),
    child: const Icon(Icons.delete, color: Colors.white),
  ),
  onDismissed: (direction) {
    final removed = items[index];
    setState(() => items.removeAt(index));   // required
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text('${removed.title} deleted'),
        action: SnackBarAction(label: 'UNDO', onPressed: () => setState(() => items.insert(index, removed))),
      ),
    );
  },
  child: ListTile(title: Text(item.title)),
)
