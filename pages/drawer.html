Material

Drawer

A panel that slides in from the edge. Put it in Scaffold.drawer and the app bar adds the burger icon for you. NavigationDrawer is the Material 3 version with selection built in.

Use it for

Secondary navigation on phones, and a permanent side menu on wide screens.

Watch out for

Scaffold.of(context) must be called below the Scaffold, so use a Builder if you open the drawer from the same build method. Close it with Navigator.pop before pushing a new route.

Example code

Scaffold(
  drawer: Drawer(
    width: 280,
    shape: const RoundedRectangleBorder(
      borderRadius: BorderRadius.horizontal(right: Radius.circular(16)),
    ),
    child: ListView(
      padding: EdgeInsets.zero,
      children: [
        const DrawerHeader(child: Text('Flutter Atlas')),
        ListTile(
          leading: const Icon(Icons.inbox),
          title: const Text('Inbox'),
          selected: current == 'Inbox',
          onTap: () {
            Navigator.pop(context);   // close first
            go('/inbox');
          },
        ),
      ],
    ),
  ),
  body: ...,
)
