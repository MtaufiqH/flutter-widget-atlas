Performance

Image size and caching

A picture takes memory based on its pixels, not its file size. A 4000 by 3000 photo needs about 48 MB once decoded, even when it is drawn in an 80 pixel box. Ask Flutter to decode it smaller with cacheWidth, and cache network images so they are not downloaded again.

Use it for

Photo lists, galleries, avatars, and any screen that shows many images.

Watch out for

Decoded size is width x height x 4 bytes. Thumbnails should be decoded at thumbnail size. cacheWidth in pixels is the logical size times the device pixel ratio. Flutter's in-memory image cache has size limits, so very large images are evicted quickly. Ask your server for a thumbnail size when it supports one.

Example code

Image.network(
  url,
  width: 80,
  height: 80,
  fit: BoxFit.cover,
);   // decodes the full 4000 x 3000 picture

// assets: same idea
Image.asset('assets/photo.jpg', cacheWidth: 300);
// load a screen's first images early
precacheImage(const AssetImage('assets/hero.jpg'), context);
