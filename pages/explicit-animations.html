Animation and motion

AnimationController & transitions

An AnimationController produces a number from 0 to 1 over a duration, and you decide what to do with it. That is what gives you repeat, reverse, pause and gesture control, which implicit animations cannot do.

Use it for

Looping animations, staggered sequences, anything driven by a drag, and animations you must stop.

Watch out for

Create it in initState with a vsync, and dispose it. Prefer AnimatedBuilder or a *Transition widget over calling setState in a listener: those repaint without rebuilding.

Example code

class _DemoState extends State<Demo> with SingleTickerProviderStateMixin {
  late final AnimationController controller = AnimationController(
    vsync: this,
    duration: const Duration(milliseconds: 1200),
  );

  late final Animation<double> _curved = CurvedAnimation(
    parent: controller,
    curve: Curves.easeInOut,
  );
  late final Animation<double> _value =
      Tween<double>(begin: 0.6, end: 1.0).animate(_curved);

  @override
  void initState() {
    super.initState();
    controller.repeat(reverse: true);
  }

  @override
  void dispose() {
    controller.dispose();   // always
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return RotationTransition(
      turns: _value,
      child: child,
    );
  }
}
