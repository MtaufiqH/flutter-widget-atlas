SegmentedButton

SegmentedButton is a row of connected choices. selected is a Set, even for a single choice, and onSelectionChanged hands you the new Set.

Use it for

A view switch, a short filter, a unit toggle. Not for navigation, which is what tabs are for.

Watch out for

Segments share the width evenly and do not scroll, so above about four short labels it gets cramped. With emptySelectionAllowed false the user cannot untick the last one.

Good to know
Widthadvice-Segments share the width evenly and do not scroll. Above about four short labels, use a dropdown or tabs.
Compared with other controlsadvice-SegmentedButton is for filtering or a view switch. For navigation use TabBar or NavigationBar, and for a form value use a Radio group.

Example code

SegmentedButton<View>(
  segments: [
    ButtonSegment(value: View.day, label: const Text('Day')),
    ButtonSegment(value: View.week, label: const Text('Week')),
    ButtonSegment(value: View.month, label: const Text('Month')),
  ],
  selected: {View.week},
  onSelectionChanged: (values) => setState(() => selected = values),
)
