Push notifications with Firebase (FCM)

With Firebase Cloud Messaging (FCM), your server sends a message to Google, and Google delivers it to the phone (through Apple's APNs on iOS). Which part of your code runs depends on the app state (foreground, background or closed) and on the kind of message.

Use it for

Chat messages, order updates, reminders, and any alert you send from a server.

Watch out for

Ask for permission on iOS and on Android 13 and above. Send the device token to your server and refresh it when it changes. The background handler must be a top-level function. A foreground app does not show a notification by itself, so show your own with flutter_local_notifications. Data-only messages on iOS are not reliable when the app is closed. Set up the APNs key in the Firebase console. Check the FlutterFire docs for current steps.

Example code

// pubspec: firebase_core, firebase_messaging, flutter_local_notifications
// terminal:  dart pub global activate flutterfire_cli && flutterfire configure

@pragma('vm:entry-point')                       // top-level, not inside a class
Future<void> _onBackground(RemoteMessage m) async {
  await Firebase.initializeApp();
  // handle m.data (not called for notification messages)
}

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
  FirebaseMessaging.onBackgroundMessage(_onBackground);

  final fm = FirebaseMessaging.instance;
  await fm.requestPermission();                 // iOS and Android 13+
  final token = await fm.getToken();            // send this to your server
  fm.onTokenRefresh.listen(sendTokenToServer);

  FirebaseMessaging.onMessage.listen((m) {      // app is open
    showLocalNotification(m);                   // the system will not show it
  });
  FirebaseMessaging.onMessageOpenedApp.listen((m) {   // tapped, from background
    router.go(m.data['route'] ?? '/');
  });
  final first = await fm.getInitialMessage();   // tapped, from terminated
  if (first != null) router.go(first.data['route'] ?? '/');

  runApp(const MyApp());
}

// iOS: upload your APNs key (.p8) in Firebase console > Project settings > Cloud Messaging
// Android 13+: <uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
